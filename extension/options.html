Custom destinations

Jump to your own sites with njt <package> <keyword>. {package} in the URL is replaced with the package name. They are suggested before built-in ones, and replace a built-in destination with the same keyword.

For example, keyword j, name jsdocs and URL https://www.jsdocs.io/package/{package} make njt prettier j open API docs on jsdocs.io.
