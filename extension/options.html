Add a custom destination

Jump to your own sites with njt <package> <keyword>. {package} in the URL is replaced with the package name. A custom destination replaces a built-in one with the same keyword.

For example, keyword j, name jsdocs and URL https://www.jsdocs.io/package/{package} make njt prettier j open API docs on jsdocs.io.

Reset

Delete all custom destinations and go back to the default order, with every destination suggested. Synced settings are reset in your other browsers too.
